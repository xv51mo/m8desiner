import telebot import requests import base64 import json import time import os # --- الإعدادات الأساسية --- # الأفضل تخليها بمتغيرات البيئة أو تكتب قيمتك هنا مباشرة على جهازك فقط BOT_TOKEN = os.getenv("BOT_TOKEN", "ضع_توكن_البوت_الجديد_هنا") ALLOWED_USER_ID = int(os.getenv("ALLOWED_USER_ID", "0")) # ضع رقم حسابك (ID) في تيليجرام هنا GITHUB_TOKEN = os.getenv("GITHUB_TOKEN", "ضع_توكن_جيت_هاب_هنا") REPO_OWNER = "xv51mo" REPO_NAME = "m8desiner" BRANCH = "main" bot = telebot.TeleBot(BOT_TOKEN) HEADERS = { "Authorization": f"token {GITHUB_TOKEN}", "Accept": "application/vnd.github.v3+json" } def upload_to_github(file_path, content_bytes, commit_msg, sha=None): url = f"https://api.github.com/repos/{REPO_OWNER}/{REPO_NAME}/contents/{file_path}" encoded_content = base64.b64encode(content_bytes).decode("utf-8") data = { "message": commit_msg, "content": encoded_content, "branch": BRANCH } if sha: data["sha"] = sha res = requests.put(url, headers=HEADERS, json=data) return res.status_code in [200, 201], res.json() def get_github_file(file_path): url = f"https://api.github.com/repos/{REPO_OWNER}/{REPO_NAME}/contents/{file_path}?ref={BRANCH}" res = requests.get(url, headers=HEADERS) if res.status_code == 200: data = res.json() content = base64.b64decode(data["content"]).decode("utf-8") return content, data["sha"] return None, None @bot.message_handler(commands=['start']) def welcome(message): if message.from_user.id != الوصف`\n\n" "• التصنيف: اكتب `a` للخط العربي، أو `b` للكولاج وفن مفاهيمي.\n" "• مثال:\n" "`نبض الحرف | a | تكوين خطي حديث بتباين لوني قوي`", parse_mode="Markdown" ) @bot.message_handler(content_types=['photo']) def handle_photo(message): if message.from_user.id != ALLOWED_USER_ID: bot.reply_to(message, "عذراً، هذا البوت خاص بصاحب الموقع فقط.") return caption = message.caption or "" parts = [p.strip() for p in caption.split("|")] if len(parts) < 2 or not parts[0]: bot.reply_to( message, "⚠️ صيغة الوصف غير مكتملة!\n" "اكتب الكابتشن بهذا الشكل:\n" "`العنوان | a أو b | الوصف`", parse_mode="Markdown" ) return title = parts[0] category = parts[1].lower() if parts[1].lower() in ['a', 'b'] else 'a' description = parts[2] if len(parts) > 2 else "" status_msg = bot.reply_to(message, "⏳ جاري رفع الصورة وتحديث `works.json`...", parse_mode="Markdown") try: # 1. تحميل أعلى دقة للصورة من تيليجرام file_info = bot.get_file(message.photo[-1].file_id) downloaded_file = bot.download_file(file_info.file_path) # اسم فريد للصورة داخل مجلد المشروع img_filename = f"work_{int(time.time())}.jpg" # 2. رفع الصورة إلى GitHub ok_img, err_img = upload_to_github( img_filename, downloaded_file, f"Add artwork: {title}" ) if not ok_img: bot.edit_message_text( f"❌ فشل رفع الصورة إلى GitHub:\n{err_img.get('message', '')}", message.chat.id, status_msg.message_id ) return # 3. قراءة وتحديث ملف works.json json_text, sha = get_github_file("works.json") works_list = json.loads(json_text) if json_text else [] new_work = [img_filename, title, category, description] works_list.insert(0, new_work) updated_json = json.dumps(works_list, ensure_ascii=False, indent=2).encode("utf-8") ok_json, err_json = upload_to_github( "works.json", updated_json, f"Update works.json with: {title}", sha=sha ) if ok_json: cat_label = "خط عربي" if category == "a" else "كولاج وفن مفاهيمي" bot.edit_message_text( f"✅ تم رفع التصميم وتحديث الموقع بنجاح!\n\n" f"🖼️ الملف: `{img_filename}`\n" f"📌 العنوان: {title}\n" f"📂 القسم: {cat_label}\n" f"📝 الوصف: {description or '—'}\n\n" f"⏳ سيظهر خلال لحظات على الموقع.", message.chat.id, status_msg.message_id, parse_mode="Markdown" ) else: bot.edit_message_text( f"⚠️ رُفعت الصورة (`{img_filename}`) لكن فشل تحديث `works.json`:\n{err_json.get('message', '')}", message.chat.id, status_msg.message_id, parse_mode="Markdown" ) except Exception as e: bot.edit_message_text( f"❌ حدث خطأ غير متوقع:\n{str(e)}", message.chat.id, status_msg.message_id ) if __name__ == "__main__": print("بوت m8desiner يعمل
